## 🚀 Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Launch Interactive Command Center (Streamlit)
```bash
streamlit run app.py
```

### 3. Open Puter.js AI Studio without Protocol Errors
```bash
python serve.py
```
This automatically starts a local server on port 8000 and opens `http://localhost:8000/puter_runner.html` in your browser.
